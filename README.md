# Apache Web Server Administration

Solution to the Apache Web Server Administration exercise at https://github.com/arturomorarioja/apache_admin_start.

It contains a Docker container with three PHP8 websites and a working Apache Web Server installation fulfilling all exercise requirements.

## Start

```bash
docker compose up -d --build
```

The web server should be available at `http://localhost:8080/`.

## Tools
Apache 2.4 / PHP8 / Water.css / HTML5
